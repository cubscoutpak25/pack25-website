# Cub Scout Pack 25 V2 Website

This updated repository contains the source code for the heavily upgraded Cub Scout Pack 25 website. 

## Updates in this Version:
1. **Multi-Page Layout:** Separated into `index.html`, `dens.html`, and `calendar.html`.
2. **Interactive Den Links:** The Dens page features an interactive accordion listing the *Required Adventures* for Lions, Tigers, Wolves, Bears, Webelos, and Arrow of Light.
3. **Dedicated Calendar:** A visually appealing timeline of your specific 2026-2027 Pack 25 events (Pinewood Derby, Campouts, Blue & Gold).
4. **Boy-Focused Photography:** Integrated high-quality, outdoor placeholder images featuring boys camping and hiking. *(Note: Unsplash does not have official BSA uniform photos. For the best result, you should replace the Unsplash links in the HTML with URLs of your own pack's boys in uniform once hosted).*

## Hosting on GitHub Pages
1. Extract the contents of this ZIP file.
2. In your GitHub repository, click **Add file** > **Upload files**.
3. Drag and drop `index.html`, `dens.html`, `calendar.html`, `styles.css`, and `script.js` into the box.
4. Click **Commit changes**.
5. Go to **Settings > Pages**, set the branch to `main`, and click **Save**.
